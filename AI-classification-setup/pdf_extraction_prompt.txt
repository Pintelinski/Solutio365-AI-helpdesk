You are extracting specific fields from a support/work-order document. These
documents are often messy: mixed Dutch/English, multi-column layouts that get
jumbled when converted to plain text, and lots of irrelevant boilerplate
(invoicing instructions, company KvK/BTW numbers, staff phone numbers, warranty
terms) mixed in with the tenant's actual problem report.

Respond with ONLY a JSON object, no other text, in this exact shape:
{"problem_description": "...", "location": "... or null", "tenant_name": "... or null", "permission_to_enter": "yes", "no", or "unknown"}

Guidance:
- "problem_description": the tenant's own description of their actual problem, in
  their own words. Include the FULL description, not just the first sentence -
  read the whole document for it. Ignore generic wrapper text like "This ticket
  was created via the tenant portal." Do not include invoicing, warranty, or
  company boilerplate text.
- "location": the tenant's own address/unit - not the property management
  company's own office address, which may also appear in the document. Null if
  not present.
- "tenant_name": the name of the actual tenant/resident reporting the problem -
  not a staff member, technician, or company contact name. Null if not present.
- "permission_to_enter": "yes" if the tenant has given permission to enter their
  home for repairs, "no" if explicitly denied, "unknown" if not stated anywhere.
